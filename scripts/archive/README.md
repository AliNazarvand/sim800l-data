## schema_autofix.py (archived 2026-10-10)

**دلیل archive:**
- این اسکریپت schema را از داده می‌ساخت. این **برعکس R15** است («اول schema، بعد داده»).
- نتیجه: schema به یک نسخه‌برداری از داده تبدیل شد، نه یک قرارداد.
- validate.py پس از اجرای این اسکریپت، **هیچ خطایی نمی‌دهد** چون schema و داده دقیقاً یکی شده‌اند.

**جایگزین:** schemaها باید **دستی** و بر اساس بخش ۷ پرامپت بازنویسی شوند.

**اگر لازم شد دوباره اجرا شود:**
```bash
python scripts/archive/schema_autofix.py
```
اما نتیجه باید به‌عنوان **debug info** استفاده شود، نه source of truth.
